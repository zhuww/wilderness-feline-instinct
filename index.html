🐈 猫朋友

走近流浪猫按 F 抚摸它——猫头顶会弹出操作菜单，可以 喂食（三文鱼/老鼠）并 收养（亲密度达到 60 ♥）。粉色气味标记猫的位置。

📖 生存指南

🎮 操作

WASD / 方向键 — 移动 Shift — 潜行（藏进高草丛） 空格 — 扑击 / 攻击 E — 嗅探（气味流） Q — 梳理毛发（+心情） F — 互动 / 抚摸 / 钓鱼 R — 召唤伙伴猫作战（5 分钟冷却） I / B / G — 打开面板 Esc — 关闭面板

👃 嗅觉本能

按下 E，彩色气味流会随风告诉你周围有什么：

青色 — 干净的水源泉水
金色 — 猎物：老鼠、三文鱼、蚱蜢
粉色 — 友好的流浪猫
红色 — 捕食者：野猪、毒蛇、狐狸
橙色 — 入侵领地的对手猫

顶部「本能」罗盘始终指向最近的各种气味来源。

🐾 生存小贴士

  • 在泉水（青色）喝水，在河岸按 F 钓鱼。
  • 下雨会打湿毛发——湿毛会拖慢体力回复。合成树叶雨帽或在洞穴火堆旁烘干。
  • 潜行穿过高草丛避开捕食者，再扑击致命一击。
  • 洞穴是安全庇护所：在床上睡到天亮恢复生命，在火堆旁烤三文鱼。
  • 按 Q 梳理毛发提升心情；心情过低会持续削弱你。
  • 交好流浪猫（粉色）——亲密度高了它们会预警危险、并肩作战。
  • 猫薄荷是很强的提神草药……但会引发"疯狂跑酷"。慎用。

🔨 合成配方

  • 树叶雨帽 — 树叶 ×3 + 藤蔓 ×2（防御：受伤 -2）
  • 鱼骨项圈 — 鱼骨 ×3 + 筋腱 ×1（攻击 +3，友情获取 +50%）
  • 猫牙项链 — 鱼骨 ×4 + 筋腱 ×2（攻击 +20%）
  • 干猫薄荷 — 猫薄荷 ×2（需要白天）
  • 草药膏 — 草药 ×3 + 野猪油 ×1

📈 成长与技能

  • 每个行为都会获得经验——捕猎、钓鱼、采集、宠物、挑战、击败 Boss。升级提升最大生命 / 体力 / 心情。
  • 升级、挑战胜利、击败 Boss 都会获得技能点。在 📈 成长面板里自由点亮三大分支：🎯狩猎（扑击/嗅觉/钓鱼）、🛡️生存（速度/减伤/潜行）、🐈羁绊（友情/心情/召唤强化）。
  • 不同分支决定你的玩法：猎手输出流、生存苟活流、还是猫群羁绊流——选择不可逆，谨慎加点。

⛩ 区域与 Boss

  • 地图边缘有传送门通往新区域：城市小区（5 级）、干燥荒野（10 级）、幽暗森林（15 级）。等级不够会被拦下。
  • 每个区域一角都盘踞着关底 Boss：巨野猪（冲撞）、弹弓顽童（远程石子）、巨狼（极速撕咬）、巨蛇（扑击）。击败它们奖励大量经验 + 3 技能点。
  • Boss 靠近时屏幕上方会出现血条；扑击是主要输出手段。
