👃 嗅觉本能

按下 E，彩色气味流会随风告诉你周围有什么：

青色 — 干净的水源泉水
金色 — 猎物：老鼠、三文鱼、蚱蜢
粉色 — 友好的流浪猫
红色 — 捕食者：野猪、毒蛇、狐狸
橙色 — 入侵领地的对手猫

顶部「本能」罗盘始终指向最近的各种气味来源。

🐾 生存小贴士

  • 在泉水（青色）喝水，在河岸按 F 钓鱼。
  • 下雨会打湿毛发——湿毛会拖慢体力回复。合成树叶雨帽或在洞穴火堆旁烘干。
  • 潜行穿过高草丛避开捕食者，再扑击致命一击。
  • 洞穴是安全庇护所：在床上睡到天亮恢复生命，在火堆旁烤三文鱼。
  • 按 Q 梳理毛发提升心情；心情过低会持续削弱你。
  • 交好流浪猫（粉色）——亲密度高了它们会预警危险、并肩作战。
  • 猫薄荷是很强的提神草药……但会引发"疯狂跑酷"。慎用。

🔨 合成配方

  • 树叶雨帽 — 树叶 ×3 + 藤蔓 ×2（防御：受伤 -2）
  • 鱼骨项圈 — 鱼骨 ×3 + 筋腱 ×1（攻击 +3，友情获取 +50%）
  • 猫牙项链 — 鱼骨 ×4 + 筋腱 ×2（攻击 +20%）
  • 干猫薄荷 — 猫薄荷 ×2（需要白天）
  • 草药膏 — 草药 ×3 + 野猪油 ×1
  • 猫薄荷茶 — 猫薄荷 ×1 + 草药 ×1（体力 +25，瞬间恢复）
  • 活力药剂 — 猫薄荷 ×2 + 草药 ×2 + 野猪油 ×1（体力 +55，需【草药炼金】技能）
  • 火焰红宝石吊坠 — 红宝石 ×1 + 鱼骨 ×2 + 筋腱 ×1（攻击 +40%）
  • 蓝宝石星坠 — 蓝宝石 ×1 + 鱼骨 ×2 + 筋腱 ×1（攻击 +25%、暴击 +12%）
  • 翡翠护身符 — 翡翠 ×1 + 树叶 ×2 + 藤蔓 ×2（每次受伤 -6）
  • 藤甲 — 藤条 ×3 + 树叶 ×2 + 藤蔓 ×2（受伤 -7、雨中几乎不湿身）
  • 石爪 — 红宝石 ×1 + 筋腱 ×2 + 鱼骨 ×2（攻击 +8，显著提升伤害）
  • 龙血药剂 — 龙血草 ×2 + 草药 ×1 + 野猪油 ×1（回 60 生命，需【草药炼金】）

📈 成长与技能

  • 每个行为都会获得经验——捕猎、钓鱼、采集、宠物、挑战、击败 Boss。每升 1 级永久增加最大生命 +10、最大体力 +6、最大心情 +6，体力恢复速度也随等级加快。
  • 升级、挑战胜利、击败 Boss 都会获得经验；但技能点只在升级时获得（每级 +1），务必谨慎规划。在 📈 成长面板里自由点亮五大分支：🎯狩猎、🛡️生存、🐈羁绊、💨闪避、🔨制作。
  • 猎手本能（伤害）、飞扑袭杀（扑击距离）、厚实毛皮（减伤）、活力充盈（体力恢复）、灵动闪避（闪避率）、能工巧匠（制作效果）都可以重复加点，成长潜力巨大。
  • 草药炼金解锁活力药剂；猫薄荷茶也是瞬间恢复体力的好帮手——体力见底时别忘了喝一口。
  • ⚖️ 动态难度：怪物、Boss 与挑战的强度会随你的等级同步成长（荒野草原 < 城市小区 < 干燥荒野 < 幽暗森林，场景越深基础越强）——等级再高也不能掉以轻心，挑战与奖励都随之提升。
  • 🐾 成长节奏：怪物密度随等级提升（每 5 级 +30%），场景内怪物会缓慢补刷，升级所需经验曲线更平缓——深入更高级的场景刷怪升级更快，不必死守一个区域。

⛩ 区域与 Boss

  • 地图边缘的传送门通往新区域：城市小区、干燥荒野、幽暗森林——无等级限制，随时可以自由进出往返。
  • 每个区域右下角都盘踞着关底 Boss：巨野猪（冲撞）、弹弓顽童（远程石子）、巨狼（极速撕咬）、大眼镜蛇——最终 Boss，体型巨大，会喷射毒液（击中后持续中毒掉血）与远距离扑击（扑击前会高高支起身体）。它守护着通往下一场景的传送门——想要推进主线，就得先过 Boss 这一关。击败它们奖励大量经验（技能点仍只来自升级）。
  • 🌋 干燥荒野有大型火山口（熔岩不可通行）和宝石矿脉；泉水稀少、几乎不下雨——靠仙人掌果补水，采龙血草和宝石制作强效道具。
  • 🌲 幽暗森林是一条纵贯的长路，两侧是无法通行的高大树木林，多雨——采集藤条编藤甲防雨防身，路上还有凶猛的猴子、鳄鱼和灵芝。
  • 🛏 城市小区的狭窄暗巷和幽暗森林的树洞都是可以睡觉的避难所——睡到天亮恢复 40 生命、体力全满。
  • Boss 靠近时屏幕上方会出现血条；扑击是主要输出手段。
